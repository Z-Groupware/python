# silero-vad 모델 파일

AI-01(VAD 절단점 계산)이 쓰는 ONNX 모델을 **이 디렉터리에 둔다.**

    models/silero_vad.onnx

## 왜 이미지에 넣는가

런타임에 받아오지 않는다. 모델이 바뀌면 절단점이 바뀌는데, 그게 배포와 무관하게 조용히
일어나면 "어제와 오늘의 블록 경계가 다른" 이유를 아무도 못 찾는다. 이미지에 박아 두면
모델 교체가 곧 배포이고, 그 시점이 커밋 이력에 남는다.

## 받는 곳

silero-vad 공식 배포본(v5, ONNX)이다. 받아서 위 경로에 `silero_vad.onnx` 로 둔다.
받은 파일의 체크섬을 커밋 메시지에 남겨 두면 나중에 같은 파일인지 확인할 수 있다.

## 없으면

`AI-01` 이 `VAD_MODEL_MISSING`(PERMANENT)으로 거절한다. 조용히 통과시키지 않는다 —
모델 없이 도는 VAD 는 무음을 하나도 못 찾아 모든 블록이 FALLBACK_OVERLAP 이 되고,
그건 "절단이 잘 안 되는 회의"로 위장된다.

## 인터페이스 (app/vad/silero.py 가 기대하는 것)

    입력  input  float32 [1, 512]   16kHz 프레임 하나
          state  float32 [2, 1, 128] 직전 프레임의 은닉 상태
          sr     int64              16000
    출력  [0]    발화 확률 [1, 1]
          [1]    다음 state

버전이 올라가 이 모양이 바뀌면 `silero.py` 를 함께 고쳐야 한다.
